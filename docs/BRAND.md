# HatchFi · Brand Kit

> **BUIDL name**: HatchFi  
> **Technical name**: Compliant RWA Issuance Agent (Pharos Skill)  
> **Tagline**: Where compliant RWAs hatch into Agent Skills  
> **中文 tagline**: 合规 RWA 孵化成可复用 Agent Skill 的飞轮

## Why HatchFi

| Old | Problem |
|---|---|
| Compliant RWA Issuance Agent | 47 characters, descriptive but forgettable, sounds like internal tooling |

| New | Why it works |
|---|---|
| **HatchFi** | 8 chars · hatch = spawn flywheel · Fi = RealFi · easy to say in English & Chinese ("哈奇Fi") |

**Memorable hook for judges**: *"Every RWA you hatch leaves a Skill behind."*

## Brand voice

- **Tone**: Industrial-refined · technical but not cold · confident, evidence-backed
- **Avoid**: generic "AI agent" purple gradients · overpromising · "one-day hackathon" dev traces
- **Emphasize**: live Atlantic proof · Skill→Skill flywheel · compliance as feature not friction
