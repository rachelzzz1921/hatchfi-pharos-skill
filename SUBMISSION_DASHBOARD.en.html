01 What it solves

The real barrier to RWAs on-chain is not "deploying a token" — it is compliance: who can hold, who they can transfer to, how to handle non-compliant addresses, and how yield is distributed. These rules must live inside the token itself and remain auditable. HatchFi packages this compliant issuance flow into an agent-operable toolkit: a read-only diligence step builds a verifiable risk rating before issuance, ERC-3643-style identity and transfer constraints enforce compliance during issuance, and each issued asset is then distilled into a reusable capability unit.

02 End-to-end pipeline diligence → issuance → reuse
STEP 01

On-chain diligence gate

Run read-only on-chain analysis on issuer and custodian addresses, producing an evidence-backed GREEN / YELLOW / RED rating. A failed rating blocks all subsequent issuance operations.

STEP 02

Compliant RWA issuance

Deploy CompliantRWAToken with unified governance over investor eligibility, restricted transfers, mint & burn, freeze & recovery, and on-chain dividends.

STEP 03

Asset Skill output

After issuance, auto-generate skills/<SYMBOL>-asset/ with the contract address and command set baked in — a capability unit other agents can call directly.

03 Contract architecture & compliance gate single-contract · ERC-3643-aligned naming

Identity module IdentityRegistry

  • OnboardingregisterIdentity / batchRegisterIdentity / removeIdentity
  • QueryisVerified / investorCountry

Compliance module ModularCompliance

  • RulescanTransfer / setComplianceRules
  • Capsmax holders, max balance per investor, holderCount

Lifecycle module

  • Supplymint / burn / forcedTransfer
  • Riskaddress freeze, partial freeze, wallet recovery, global pause

Dividend module

  • DistributedepositDividend / claimDividend / dividendOf
  • Modelcumulative per-share, no holder iteration, gas-safe

Every transfer passes the triple check of the _update() hook; mint enforces both identity and compliance caps (max holders / max balance per investor); forcedTransfer is a regulatory path that checks identity only, bypassing global compliance rules while still requiring a verified recipient.
